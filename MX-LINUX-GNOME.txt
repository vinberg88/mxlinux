Fix IP problem for X410. Cant find screen problems and other stuff. IP is importent stuff.

OPEN POWERSHELL FROM MICROSOFT AND TYPE: ipconfig

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL.

SAVE IP HERE FROM POWERSHELL: 172.30.16.1

GO BACK TO MX LinuX Terminal AND COPY AND PASTE THIS.

sudo apt install systemd-resolved chatt* e2fsprogs* -y

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1  <-- put your ip number here from Powershell and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - Problem fixed for MX LinuX and GNOME via WSL and X410 - 2026
